# Kitze reusable UI

Personal branded sections on top of Kitze UI. Keep generic primitives in kitze-ui-registry. Upstream primitives are installed via shadcn from https://ui.kitze.io; never fork them here.

Use Bun, strict TypeScript 7, oxlint/Ultracite/anti-slop and oxfmt. Preserve tools/oxlint/anti-slop/LICENSE. Shipped registry files must stay under 200 lines. Registry JSON is generated by scripts/build-registry.ts. Run bun run check and bun run build before shipping.

No dev or preview servers. Use the normal PR/production deployment flow; no draft PRs. Browser validation uses Hive on the deployed site.
